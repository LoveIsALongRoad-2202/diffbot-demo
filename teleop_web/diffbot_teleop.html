How this works: unlike terminal teleop, this page uses real browser keydown/keyup events. Holding i publishes forward velocity at 10Hz continuously; the instant you release the key (or your mouse button on a tile), a zero-velocity command is sent immediately. Both the Gazebo simulation and the real Arduino car (via serial_bridge_node) subscribe to the same /cmd_vel topic, so both respond identically and stop the moment you let go.
